# Талалаївське весілля

Односторінковий промо-сайт книги з формою замовлення.
Зроблений за специфікацією [`docs/BOOK-SITE-TEMPLATE.md`](docs/BOOK-SITE-TEMPLATE.md).

**Стек:** Next.js 16 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS v4 · googleapis · Vercel Analytics.
Без бази даних, без авторизації, без UI-кітів.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```

## Що треба заповнити перед публікацією

Увесь контент зібраний в одному файлі — [`config/book.ts`](config/book.ts). Місця, які
чекають на реальні дані, позначені `TODO`:

| Що | Де |
| --- | --- |
| Автор, надрядок-жанр, короткий опис | `BOOK` у `config/book.ts` |
| Текст «Про книгу» (4–7 абзаців) | `ABOUT.paragraphs` |
| Варіант замовлення та ціна | `VARIANTS` — зараз один варіант «Книга», ціна-заглушка «000 грн» |
| Посилання автора | `CONTENT_BLOCK.links` — порожні не рендеряться |
| Відгуки | `REVIEWS` — зараз **згенеровані заглушки**, замінити реальними. На лендінгу — `REVIEWS_PREVIEW_COUNT` випадкових, на `/reviews` — усі |
| Тексти режиму «Подарунок бібліотеці» у формі замовлення | `GIFT` |
| Обкладинка | `public/cover.png` — зараз там плейсхолдер |
| Домен і посилання на оплату | змінні оточення (нижче) |

## Змінні оточення

Скопіюйте `.env.example` у `.env.local` і заповніть. Усі інтеграції **опційні й незалежні**:
якщо змінних немає — канал тихо вимикається, а замовлення однаково приймається й
покупець бачить номер замовлення (принцип «мʼякої деградації»).

| Змінна | Навіщо |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | продакшн-домен для `metadataBase`, canonical і OG |
| `NEXT_PUBLIC_PAYMENT_URL` | посилання на оплату. Потрібне для онлайн-оплати; поки порожнє, замовлення приймається, але покупця нікуди не перекидає. Післяплата працює й без нього |
| `NEXT_PUBLIC_PREORDER_ENABLED` | `true` вмикає банер передзамовлення |
| `GOOGLE_SHEETS_*` | запис замовлень у таблицю |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | сповіщення в Telegram |
| `RESEND_*` | сповіщення на email |

Налаштування Google Sheets / Telegram / Resend — розділ 5 специфікації.
Колонки таблиці: `Час | № замовлення | Варіант | Спосіб оплати | ПІБ | Телефон | Контакт | Місто | Відділення`.

Подарунки бібліотекам (перемикач «Подарунок бібліотеці» у тій самій формі) пишуться в той самий аркуш:
у «Варіанті» — позначка 🎁 і кількість, доставка порожня, а дані бібліотеки — в додатковій 10-й колонці `Бібліотека`.

Відгуки, надіслані через «Залишити відгук», приходять у Telegram (і на пошту, якщо вона налаштована). На сайт самі не потрапляють — їх додають руками в `REVIEWS`.

## Деплой

1. Запушити репозиторій у GitHub.
2. Імпортувати проєкт у Vercel (фреймворк визначиться сам).
3. Додати змінні оточення (Production + Preview). `GOOGLE_SHEETS_PRIVATE_KEY` — з `\n` замість переносів рядка.
4. Підключити домен, дочекатися сертифіката, звірити його з `NEXT_PUBLIC_SITE_URL`.
5. Зробити тестове замовлення на проді обома способами оплати.

## Структура

```
app/
  layout.tsx           шрифти, метадані, SEO/OG, Analytics
  page.tsx             лендінг (server component)
  reviews/page.tsx     усі відгуки
  gallery/page.tsx     фотогалерея «до/після»
  globals.css          Tailwind + CSS-змінні світлої теми
  api/order/route.ts   замовлення (для себе або подарунок бібліотеці) → Google Sheets + Telegram + Email
  api/question/route.ts питання → Telegram + Email
  api/review/route.ts  відгук → Telegram + Email
components/
  OrderForm.tsx        форма замовлення (перемикач «Для себе / Подарунок бібліотеці») + модалка успіху
  QuestionModal.tsx    модалка «Задати питання» (honeypot + кулдаун 60 с)
  ReviewModal.tsx      модалка «Залишити відгук» (honeypot + кулдаун 60 с)
  ReviewsPreview.tsx   випадкові відгуки на лендінгу
  Modal.tsx            спільна оболонка модальних вікон
  Ornament.tsx         стрічка з листя барвінку (шапка й футер)
config/book.ts         ЄДИНЕ ДЖЕРЕЛО ПРАВДИ: контент, варіанти, ціни, посилання
lib/notify.ts          канали сповіщень: Telegram, Email, Google Sheets
lib/payment.ts         перехід на оплату (замовлення й подарунок)
lib/escape.ts          екранування даних для HTML-листів
public/cover.png       обкладинка
```
